# Ещё 20 подходов к полировке Arcane UI

Ветка: `reskin/arcane-watercolor`.
Игра: https://andreyvoytov-mushrooms-arcane.pages.dev/

Каждый подход включает исходные снимки, проверку конкретного ансамбля,
правку при необходимости и повторный просмотр. Для проблемных состояний
сделаны дополнительные промежуточные проверки. Итоговая сборка отдельно
проверяется целиком и после публикации.

## Измерения и проверка

[qa-final.json](qa-final.json) содержит итоговые снимки с измерениями,
выборочный контраст текста, сравнение высоты букв до/после, проверку
пересечений текстовых блоков, ошибки выполнения, переходы и 17 регрессий.
Проверка контраста использует пиксели настоящего фона без текста, а не
предположение о цвете подложки. Высота букв измеряется в CSS-пикселях
на экране шириной 390 пикселей, без невидимых полей шрифта.

Например, шестизначный баланс вырос с 7,65 до 12,17 пикселя по медианной
высоте глифа; длинное название задания — с 7,24 до 9,47; описание
артефакта — с 6,51 до 9,17. Самые узкие экраны отдельно просмотрены:
вспомогательные подписи там остаются меньше главных действий.

Промежуточные неудачные варианты используются как диагностика и не
входят в итоговые показатели. Из проверки пересечений исключено
намеренное наложение содержимого клеток. Тестовый прогресс создавался
в отдельных браузерных профилях. Основная рабочая копия и исходная
версия игры не изменялись.

## Растровые ресурсы

Новый фон: [assets/backpack/panel.png](../../../assets/backpack/panel.png).
Он создан встроенным ImageGen; [полный промпт и референсы](imagegen-prompts.json).
Нормализация: `node tools/prepare-arcane-backpack.cjs <selected-master.png>`.

Размер остался **973×1413**, как у оригинала. Мастер не публикуется.
В игре используется лениво загружаемый WebP-атлас рюкзака — **324 772 байта**
вместо прежних 177 570; он загружается при открытии рюкзака. Остальные
атласы не перепаковывались. Проверены прежние 609 текстур и новый
ресурс: увеличения исходных разрешений нет. [Бюджет ресурсов](asset-budget.json).

Снимки для сравнения сохраняются в `.local-workbench/ui-reviews/twenty/`.
Отобранные обзоры ниже служат QA-иллюстрациями и не загружаются игрой.

## Опубликованная сборка

Повторный прогон с Cloudflare прошёл: 12 основных экранов и 6 состояний
рюкзака/экипировки, включая настоящий клик «Надеть» и возврат к Борису.
Побайтово проверены 80 опубликованных файлов, метаданные, шрифты,
редирект архива и ссылка существующей карточки в трекере.

Начальная загрузка: **22 466 845 байт**, прежний замер — 22 466 028
(разница **+817 байт**). Новый атлас рюкзака при старте не загружается.
Оригинальная версия игры сохранила прежнюю контрольную сумму.
