Правила оценки запуска

Сначала проверить полноту событий, исключить тестовые профили и собрать зрелые когорты. Затем сопоставить удержание, прохождение, расход энергии и скорость потребления контента с пилотом. Долю платящих и ARPDAU считать только после подключения подтверждённой выручки платформы.

Пороги go / no-go назначаются по результатам пилота; выдача товара не доказывает доход.
