# Полевая тетрадь

## Локальный запуск

Из корня проекта выполните:

```powershell
npm run mechanics
```

Откройте `http://127.0.0.1:4173/`. Остановка сервера — `Ctrl+C`.

Локальный сервер отдаёт файлы с локального компьютера. До подключения Supabase изменения сохраняются только в текущем браузере. Кнопка «Загрузить копию» принимает JSON-файл, созданный кнопкой «Выгрузить данные», чтобы перенести прежние карточки и изображения. Настройка общей базы описана в [supabase/README.md](supabase/README.md).

## Публикация

Каталог можно разместить как статический сайт GitHub Pages по пути `/mechanics/`. Общая синхронизация карточек и изображений требует настроенного проекта Supabase.
