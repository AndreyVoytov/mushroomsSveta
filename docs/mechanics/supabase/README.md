# Подключение общего каталога Supabase

## Настройка проекта

1. В Supabase SQL Editor выполните `setup.sql`, заменив все `OWNER_EMAIL_HERE` на email владельца каталога.
2. В Authentication → URL Configuration добавьте разрешённые адреса возврата:
   - `https://andreyvoytov.github.io/mushroomsSveta/mechanics/`
   - `http://127.0.0.1:4173/`
3. Заполните в `cloud-config.js` Project URL и publishable key. Email владельца туда не записывается: приложение проверяет право редактирования через SQL-функцию `is_mechanics_owner()`.
4. Запускайте локально командой `npm run mechanics`.

Supabase хранит карточки и новые пользовательские изображения. Каталог открыт для чтения, а добавление и изменение карточек и загрузка изображений разрешены только владельцу через RLS. Картинки, включённые в сборку каталога, остаются файлами Pages.

Вход по email отправляет одноразовую ссылку. Даже если другой пользователь создаст Auth-сессию, серверные политики Supabase не разрешат ему менять каталог.

В публичном клиентском коде используйте только publishable/anon key. Пароль базы, secret key и `service_role` нельзя помещать в сайт.
