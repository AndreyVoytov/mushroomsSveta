## 2. Обязательный список новых картинок

Это минимум, который нужен, если продолжать игру до 500 уровней не только уровнями, но и новой сюжетной подачей.

### 2.1. Новые персонажи

- Ворон-архивариус: 3 эмоции
  - нейтральный
  - недовольный
  - довольный / объясняющий
- Выдра-мельничиха: 3 эмоции
  - спокойная
  - рабочая / занятая
  - радостная
- Барсучиха-травница: 3 эмоции
  - серьёзная
  - удивлённая
  - добрая
- Мотылёк-фонарщик: 2 состояния
  - обычный
  - светящийся
- Морок Забвения: 3 состояния
  - слабый
  - активный
  - растворяющийся

### 2.2. Новые локации / фоны

Для каждой локации желательно иметь минимум 1 основной фон и 2-4 крупных сюжетных объекта поверх него.

- Снежный перевал
- Хрустальный овраг
- Ледяная обсерватория
- Корневая тропа
- Ночная оранжерея
- Лунная пристань
- Гнёзда совиной почты
- Мельничная запруда
- Мшистый амфитеатр
- Ярмарка у избушки

### 2.3. Сюжетные предметы и декор

- Ключ дорог
- Карта-семя
- Корневой фонарь
- Почтовая сумка совиной почты
- Кристалл маршрута
- Осколок обсерватории
- Дорожная печать
- Указатель совиной почты
- Лунный фонарь
- Ярмарочные флажки
- Праздничная гирлянда
- Короб для доставки Бориса

## 3. Желательно, но можно отложить

### 3.1. Для дневника и карты

- 5-8 новых иллюстраций для дневника
- 3-5 новых мини-иконок для карты
- 1 новая картинка для финального разворота дневника

### 3.2. Для UI и событий

- 1 картинка для нового chapter/event splash
- 3-5 маленьких иконок сюжетных предметов
- 1 иллюстрация для финального праздника

## 4. Если делать новые биомы честно, а не через рескин

Если биомы будут не просто вариацией существующих клеток, а реально новыми наборами арта, тогда нужен ещё отдельный пакет.

### 4.1. Наборы клеток

- Морозный хребет
- Хрустальная осыпь
- Болотный мох
- Ночной сад
- Корневой лабиринт

### 4.2. Для каждого нового биома отдельно

- базовая клетка
- затемнённая клетка
- рамка клетки
- трава / поверхность
- спецпокрытие
- 1-2 декоративных объекта
- 1-2 уникальных препятствия

## 5. Самый дешёвый пакет, если хотим быстро добить контент

Если задача именно быстро и дёшево дотянуть игру до 500 уровней, я бы заказывал только это:

- 4 новых фона
  - Снежный перевал
  - Хрустальный овраг
  - Ночная оранжерея
  - Лунная пристань
- 1 новый персонаж
  - Ворон-архивариус, 3 эмоции
- 6 новых предметов / декоров
  - ключ дорог
  - карта-семя
  - корневой фонарь
  - почтовая сумка
  - кристалл маршрута
  - финальные флажки / гирлянды
- 2-3 эффекта для Морока Забвения
- 3-4 картинки для дневника

## 6. Что я бы не заказывал в первую очередь

- Полный новый набор портретов для уже существующих персонажей
- Отдельный арт-пак для всех 5 новых биомов сразу
- Сложные анимированные фоны для каждой новой локации
- Новые версии всех UI-иконок

Сначала лучше закрыть сюжетный минимум, а уже потом расширять визуальное богатство.
