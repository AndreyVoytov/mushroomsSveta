# Аудит игры от 14 октября 2026

Откройте `index.html` в браузере. Это один автономный HTML-файл: данные, стили и логика встроены, интернет и сервер не нужны. Выбор, комментарии и изменённые приоритеты сохраняются локально в браузере; JSON-экспорт позволяет перенести выбор. Markdown и текст удобны для передачи задач в чат.

Кнопка «Удалить» в карточке убирает пункт из списка, снимает его галочку и исключает из экспортируемых задач. Удаление сохраняется в браузере. Через фильтр «Удалённые» пункт можно восстановить вместе с комментарием и приоритетом; после восстановления галочку нужно поставить заново. JSON-экспорт также сохраняет список удалённых и их настройки для переноса между браузерами. «Добавить все P0» не возвращает удалённые пункты.

В отчёте 61 пункт: ошибки по коду, риски для проверки, незавершённые системы и предложения развития. Для каждого указаны основания, последствия, решение и критерий готовности. Исходный commit встроен в страницу и экспорт. Backend, реальные оплаты, прохождение всей кампании и реальные мобильные устройства не проверялись.

## Источники и обновление

Содержимое аудита: `tools/build-game-audit.js`. Шаблон страницы: `tools/game-audit-template.html`.

Пересборка из корня проекта:

```sh
node tools/build-game-audit.js
```

Генератор проверяет ID, зависимости и существование ссылок на строки исходников, пересчитывает новизну уровней и выполняет изолированные диагностические пробы. Текст выводов редактируется вручную: пересборка сама не превращает старый аудит в актуальный после исправления игры. После изменений нужно пересмотреть выводы и повысить версию отчёта.

```sh
node tools/audit-reproduce.js
```

Эта команда воспроизводит поведение исторической ревизии `7a9d212fa04fe2a69ab254f5baea53472f720519` с контролируемыми часами и моками I/O. После исправлений она остаётся свидетельством исходных ошибок. Текущее правильное поведение проверяет `node tools/test-world.js`; игровые сохранения обе команды не читают и не изменяют. Статус выбранных правок находится в `docs/implementation/index.html`.
