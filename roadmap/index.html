ОБ АТЛАСЕ

Вся игра на одной шкале

Уровни, обучение, сюжетные находки и реплики взяты из конфигураций игры. Нижние деления соответствуют смене целей в дневнике и на игровом прогресс-баре.

Превью: форма поля, типы клеток и закреплённые объекты берутся из маски. Случайные находки и звери расположены по примерной воспроизводимой раскладке с учётом биомов. Анимации и игровая симуляция не запускаются.

Энергия: показан параметр steps — базовое значение уровня. Это не остаток энергии у игрока и не фактический расход на прохождение.

Первое появление случайного зверя означает первый уровень, на котором он может встретиться. Завязки диалогов привязаны к уровню их события; границы сюжетных этапов — к числу пройденных уровней.

Данные обновляются в проекте командой npm run roadmap:data.
