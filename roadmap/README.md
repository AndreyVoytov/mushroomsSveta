# Атлас игры

Отдельный статический инструмент для геймдизайна. Страница не импортирует игру и не читает или меняет игровые сохранения.

## Локальный запуск

Из корня проекта:

```sh
npm run roadmap
```

Открыть http://127.0.0.1:4180/roadmap/. Порт можно изменить переменной `ROADMAP_PORT`.

## Обновить данные

```sh
npm run roadmap:data
```

Экспорт читает литералы TypeScript через AST, без исполнения игровых модулей. Источники:

- `ForestConfiguration.allForests`: порядок, маски, цели, энергия, специальные клетки.
- `SpecialItemsConfiguration`: уникальные сюжетные находки.
- `EducationPanel` и `assets/localization/ru.json`: обучение.
- `DiaryConfiguration` и `RecipeUtils`: границы целей на игровом прогресс-баре.
- `ReplicasConfiguration`, `ForestReplicasConfiguration`, `MapPresetConfiguration`: персонажи и сюжет.
- `PrizesConfiguration`: награды.

Названия этапов берутся из `titleForProgress`, если поле задано. Повторные рецепты наследуют `copyOf`. Границы нижнего маршрута обозначают число **пройденных** уровней; полевые реплики используют номер текущего уровня (`context.level + 1`).

Круг с результатом цели и её карточка стоят в конце отрезка прогресса, рядом с диалогом на этой границе. Например, суп для Бориса заканчивается после уровня 17, ягодный напиток — после 20. Последняя цель без заданного конца вынесена в продолжение справа; её положение не задаёт номер будущего уровня. В подробностях доступны реплики самого этапа и диалоги при его завершении.

## Превью

В превью используются игровые хедеры, деревянная панель целей и иконка энергии. Счётчики целей повторяют правила `ForestUtils.getAims`, включая ягоды с кустов, жемчуг и фиксированные находки дома (например, 16 слив на уровне 74). Позиции находок воспроизводимы, но могут отличаться от конкретного запуска игры.

`preview.js` рисует отдельный canvas из маски и игровых картинок. Геометрия и закреплённые в маске объекты соответствуют конфигурации. Случайные находки и животные размещаются воспроизводимо по номеру уровня, с ограничениями биомов и количества. Это иллюстрация конфигурации, а не симуляция проходимости, игрового RNG или анимации. Длинное поле показано целиком.

Впервые: отдельные символы маски, заданные цели, окружения, счётчики механик и сюжетные находки. Случайные предметы сундуков объединены в одну категорию. Для случайных животных показывается первый **возможный** уровень. Энергия — `steps`, а не фактический расход игрока.

## Управление

- Панель поиска и настроек по умолчанию скрыта. Иконка в правом верхнем углу раскрывает её поверх карты, не сдвигая маршруты.

- Колесо над любым маршрутом всегда прокручивает его влево-вправо, даже если содержимое выше панели. Ctrl + колесо сохраняет стандартный масштаб браузера. Потянуть карту мышью или пальцем можно в обе стороны.
- Навести на кружок — превью; нажать — поле, цели, обучение, открытия и реплики.
- Нижняя полоса с широкой плашкой отражает положение и размер видимой области. Плашку можно перетаскивать, нажимать на дорожку или управлять стрелками, Page Up / Down, Home / End. Поиск ищет уровень, открытие, обучение и сюжетный этап.
- Разделитель двигается мышью, пальцем и стрелками клавиатуры.
- «Общая шкала» синхронизирует оба маршрута. Масштаб, положение, слои и разделитель запоминаются в браузере.

## GitHub Pages

Публикуется каталог `docs/roadmap` как `/roadmap/` рядом с `/assets/` и `/mechanics/`. Достаточно HTML, CSS, JavaScript и игровых изображений; серверная база не нужна. Игровая сборка не меняется.
